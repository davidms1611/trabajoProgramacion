
# ♠️ BLACKJACK ♥️

![Version](https://img.shields.io/badge/Version-1.0-blue?style=for-the-badge)

## 📖 Descripción

Juego de Blackjack en Java donde compites contra
el crupier para conseguir 21 puntos sin pasarte.

## 🎮 Características

- ✅ Apuestas con dinero virtual.
- ✅ Reparto aleatorio de cartas.
- ✅ Crupier automático.
- ✅ Sistema de victorias y derrotas.
- ✅ Objetivo: duplicar el saldo inicial.

## 🃏 Valor de las cartas

| Carta | Puntos |
|:---:|:---:|
| 2 al 10 | Su valor |
| J, Q, K | 10 |
| As | 1 u 11 |

## 🚀 Ejecución

```bash
javac Main.java
java Main
```

## 📋 Reglas

<details>
<summary>Ver las reglas del juego</summary>

- No superar los 21 puntos.
- El crupier pide carta con 16 o menos.
- El crupier se planta con 17 o más.
- Ganar una ronda devuelve el doble apostado.
- El jugador puede retirarse después de cada ronda.

</details>
